# License Scope

This repository uses separate notices because source code, benchmark datasets, and public result data have different reuse expectations.

## Source and documentation

Source code, ordinary documentation, recipes, schemas, and validation code are licensed under the Apache License 2.0 in [`LICENSE`](LICENSE), unless a file carries a more specific notice.

## Canonical datasets and public result data

The original fixed benchmark datasets in `datasets/` and the sanitized public result data in `results-public/` are offered under Creative Commons Attribution 4.0 International. See [`DATASET_LICENSE.md`](DATASET_LICENSE.md), `datasets/LICENSE`, and `results-public/LICENSE`.

Attribution should identify **GB10 Local LLM Benchmark / DevSnack** and link to the repository or the relevant release.

## Excluded upstream materials

Model weights, downloaded GGUF/MMPROJ files, llama.cpp itself, third-party packages, and any external dataset or reference material are not included. Their own license and attribution terms continue to apply.

If a future dataset incorporates third-party material, its provenance and license must be recorded before it is included in a public release. The repository license cannot grant rights that the project does not own.
